# Drummysite

Allan Ward Percussion Lessons — https://allanwarddrums.com

A static site: plain HTML, one stylesheet, one small script. No build step.

## How it deploys

Cloudflare Pages is connected to this repository. Every push to `main` goes live;
every pull request gets its own preview URL (shown on the PR by the Cloudflare bot),
so changes can be checked on a phone and a laptop before merging.

## Layout

| Path | What it is |
| --- | --- |
| `index.html`, `about.html`, `contact.html` | Public pages |
| `members/schedule.html` | Client scheduling (Acuity embed). Protected by a Cloudflare Access policy on `/members/*`; also `noindex` and excluded in `robots.txt` |
| `play-along/` | Play-along etude players — self-contained pages, see below |
| `assets/styles.css` | All styling (pages carry no inline CSS) |
| `assets/site.js` | Footer year and the contact form's "sent" banner |
| `_headers` | Security headers for Cloudflare Pages (CSP etc.) — see the comments in the file |
| `robots.txt`, `sitemap.xml`, `favicon.svg`, `404.html` | The usual site furniture |

The contact form posts to Formspree; the honeypot field `_gotcha` is hidden by the `.hp` class.

## Play-along pages

`play-along/*.html` are generated by `make_playalong.py` in the DRUM PRODUCTION project
(not part of this repo) from the etude data files. Regenerate there with
`python3 make_playalong.py --site play-along` and copy the folder in; do not hand-edit
the player pages. The section index (`play-along/index.html`) is generated by the same script.

## Editing

- Each page carries its own header/nav and footer; when adding a nav item, add it to every page
  (and to `SITE_NAV` in the play-along generator).
- The Content-Security-Policy in `_headers` only allows what the site uses. If you add a
  third-party script, frame or form target, add its origin there, and check the browser
  console on the preview URL for "Refused to…" messages.
- Images: keep them web-sized (the hero is 1600 px wide, ~400 KB) and strip camera metadata.
